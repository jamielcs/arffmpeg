# arffmpeg

Paket runtime FFmpeg (ffmpeg.exe + ffprobe.exe) untuk **ARMAGIC FLOW**.

File `armagic-ffmpeg-runtime.zip` di Release v1 diunduh OTOMATIS oleh aplikasi member saat pertama kali jalan (lewat `core/ffmpeg_bootstrap.py`).

**JANGAN HAPUS REPO / RELEASE INI** - kalau hilang, aplikasi member gagal memasang FFmpeg dan fiturnya mati diam-diam (kejadian 2026: repo terhapus karena dikira tidak dipakai, ketahuan 12 Nov 2026).

Cadangan: file yang sama juga di-host di https://flow.armagic.id/downloads/armagic-ffmpeg-runtime.zip dan aplikasi otomatis jatuh ke sana bila GitHub gagal.
